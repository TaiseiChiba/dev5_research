# SCR009: 口座編集画面

## 基本情報

- **画面ID**: SCR009
- **画面名**: 口座編集画面
- **URL**: `/accounts/:accountId/edit`
- **実装ファイル**: `src/components/account/AccountEdit.tsx`
- **アクセス権限**: 認証済みユーザー（口座編集権限必要）

## データベース操作

### 使用テーブル

- **メインテーブル**: `accounts`
- **関連テーブル**: `customers`, `audit_logs`
- **操作種別**: SELECT（詳細取得）、UPDATE（情報更新）

### 口座詳細取得SQL

```sql
SELECT
  a.account_id,
  a.customer_id,
  a.account_number,
  a.account_type,
  a.status,
  a.balance,
  a.created_at,
  a.updated_at,
  c.name as customer_name,
  c.phonetic_name as customer_phonetic_name,
  c.customer_type
FROM accounts a
INNER JOIN customers c ON a.customer_id = c.customer_id
WHERE a.account_id = $1
  AND c.is_deleted = false;
```

### 口座情報更新SQL

```sql
UPDATE accounts
SET
  account_type = $1,
  updated_at = NOW()
WHERE account_id = $2
  AND status = 'ACTIVE';
```

### 監査ログ記録SQL

## イベント処理

### E001: 画面初期化

**処理順序**:

1. **URLパラメータ取得**
   - `accountId`をURLから取得
   - パラメータ検証

2. **権限確認**
   - ユーザーの口座編集権限確認
   - 権限不足の場合はアクセス拒否

3. **口座詳細データ取得**
   - `GET /api/accounts/:accountId` 呼び出し
   - `accounts`テーブルから詳細情報取得

4. **編集可能性チェック**
   - 口座ステータスが`ACTIVE`であることを確認
   - 非アクティブ口座は編集不可

5. **フォーム初期化**
   - 取得データでフォーム項目を初期化
   - 読み取り専用項目の表示

### E002: 口座種別変更

**処理順序**:

1. **変更値取得**
   - 選択された口座種別を取得

2. **変更可能性チェック**
   - 現在の口座種別から変更可能かチェック
   - 業務ルールに基づく制約確認

3. **変更警告表示**
   - 口座種別変更の影響について警告表示
   - 「口座種別を変更すると一部機能が制限される場合があります」

### E003: 保存ボタン押下

**処理順序**:

1. **入力値検証**
   - 必須項目チェック
   - 形式・制約チェック

2. **変更確認ダイアログ表示**
   - 変更内容の確認表示
   - 「以下の内容で口座情報を更新しますか？」

3. **更新API呼び出し**
   - `PUT /api/accounts/:accountId` 呼び出し
   - 口座情報更新実行

4. **更新結果処理**
   - **成功時**: 成功メッセージ表示、詳細画面に遷移
   - **失敗時**: エラーメッセージ表示、フォーム状態維持

5. **監査ログ記録**
   - `audit_logs`に更新履歴記録

### E004: キャンセルボタン押下

**処理順序**:

1. **変更確認**
   - フォームに変更があるかチェック

2. **キャンセル確認ダイアログ表示**（変更がある場合）
   - 「変更内容が破棄されます。よろしいですか？」

3. **画面遷移**
   - 口座詳細画面に遷移（`/accounts/:accountId`）

### E005: リアルタイムバリデーション

**処理順序**:

1. **入力値検証**（デバウンス300ms）
   - 口座種別の妥当性チェック

2. **エラー表示**
   - 該当項目にエラーメッセージ表示
   - 項目枠を赤色に変更

3. **保存ボタン制御**
   - バリデーションエラー時は保存ボタン無効化

## データベース操作詳細

### 編集可能性チェック

```sql
-- 口座ステータスチェック
SELECT status
FROM accounts
WHERE account_id = $1
  AND status = 'ACTIVE';

-- 進行中取引チェック
SELECT COUNT(*)
FROM transactions
WHERE (source_account_id = $1 OR destination_account_id = $1)
  AND status IN ('PENDING_VERIFICATION', 'APPROVED');
```

### 口座種別変更制約

```sql
-- 定期預金への変更時の残高チェック
SELECT balance
FROM accounts
WHERE account_id = $1
  AND balance >= 100000; -- 定期預金の最低残高
```

## エラーハンドリング

| エラー種別         | 条件                         | メッセージ                                 | 対応テーブル   |
| ------------------ | ---------------------------- | ------------------------------------------ | -------------- |
| 口座不存在         | 該当口座なし                 | 「口座が見つかりません」                   | `accounts`     |
| 編集権限不足       | 口座編集権限なし             | 「口座を編集する権限がありません」         | `users`        |

| 進行中取引存在     | 進行中取引がある状態での編集 | 「進行中の取引があるため、編集できません」 | `transactions` |
| 種別変更不可       | 業務ルールに違反する変更     | 「この口座種別には変更できません」         | `accounts`     |
| 残高不足           | 定期預金変更時の残高不足     | 「定期預金には最低10万円の残高が必要です」 | `accounts`     |
| データ取得失敗     | SQL実行エラー                | 「口座情報の読み込みに失敗しました」       | `accounts`     |
| 更新失敗           | データベース更新エラー       | 「口座情報の更新に失敗しました」           | `accounts`     |
| ネットワークエラー | API通信失敗                  | 「通信エラーが発生しました」               | -              |

## 表示フォーマット

### 口座種別選択肢

| DB値          | 表示名   | 説明                     |
| ------------- | -------- | ------------------------ |
| SAVINGS       | 普通預金 | 一般的な預金口座         |
| CHECKING      | 当座預金 | 法人向け決済口座         |
| FIXED_DEPOSIT | 定期預金 | 固定期間・金利の預金口座 |

### ステータス表示

| DB値      | 表示名   | 色      |
| --------- | -------- | ------- |
| ACTIVE    | 有効     | success |
| CLOSED    | 解約済み | default |
| SUSPENDED | 停止中   | warning |

### 残高表示フォーマット

- **形式**: `¥1,234,567`
- **色**: プライマリカラー

### 日付表示フォーマット

- **形式**: `YYYY年MM月DD日`
- **例**: `2024年01月01日`

## API仕様

### GET /api/accounts/:accountId

**レスポンス**: 口座詳細画面と同じ

### PUT /api/accounts/:accountId

**リクエスト**:

```json
{
  "accountType": "FIXED_DEPOSIT"
}
```

**レスポンス（成功）**:

```json
{
  "success": true,
  "message": "口座情報が正常に更新されました",
  "data": {
    "accountId": "ACC001",
    "accountType": "FIXED_DEPOSIT",
    "updatedAt": "2024-01-01T10:00:00Z"
  }
}
```

**レスポンス（失敗）**:

```json
{
  "success": false,
  "message": "定期預金には最低10万円の残高が必要です",
  "details": {
    "currentBalance": 50000,
    "requiredBalance": 100000
  }
}
```

## 口座種別変更ルール

### 変更可能パターン

| 現在種別      | 変更可能種別            | 条件                     |
| ------------- | ----------------------- | ------------------------ |
| SAVINGS       | CHECKING, FIXED_DEPOSIT | 各種別の条件を満たす場合 |
| CHECKING      | SAVINGS, FIXED_DEPOSIT  | 各種別の条件を満たす場合 |
| FIXED_DEPOSIT | SAVINGS, CHECKING       | 満期到来後のみ           |

### 変更制約

- **定期預金への変更**: 残高10万円以上必要
- **当座預金への変更**: 法人顧客のみ
- **定期預金からの変更**: 満期到来後のみ（実装では簡略化）
