# SCR010: 口座作成画面

## 基本情報

- **画面ID**: SCR010
- **画面名**: 口座作成画面
- **URL**: `/accounts/create`
- **実装ファイル**: `src/components/account/AccountCreate.tsx`
- **アクセス権限**: 認証済みユーザー

## データベース操作

### 使用テーブル

- **メインテーブル**: `accounts`
- **関連テーブル**: `customers`, `audit_logs`
- **操作種別**: SELECT（顧客一覧取得）、INSERT（口座作成）

### 顧客一覧取得SQL

```sql
SELECT
  customer_id,
  name,
  phonetic_name,
  customer_type,
  contact_info
FROM customers
WHERE is_deleted = false
ORDER BY name;
```

### 口座番号生成SQL

```sql
-- 口座番号生成（例：1234567890）
SELECT
  LPAD((
    SELECT COALESCE(MAX(
      CAST(account_number AS BIGINT)
    ), 1000000000) + 1
    FROM accounts
    WHERE account_number ~ '^[0-9]+$'
  )::TEXT, 10, '0') as new_account_number;
```

### 口座作成SQL

```sql
INSERT INTO accounts (
  account_id,
  customer_id,
  account_number,
  account_type,
  status,
  balance,
  created_at,
  updated_at
) VALUES (
  $1, -- 自動生成されたID
  $2, -- customer_id
  $3, -- account_number
  $4, -- account_type
  'ACTIVE', -- 初期状態
  $5, -- 初期残高（1円以上）
  NOW(),
  NOW()
);
```

### 監査ログ記録SQL

```sql
INSERT INTO audit_logs (
  log_id,
  user_id,
  action,
  entity_type,
  entity_id,
  new_values,
  timestamp
) VALUES (
  $1, -- UUID
  $2, -- user_id
  'CREATE_ACCOUNT',
  'ACCOUNT',
  $3, -- account_id
  $4, -- 作成された口座情報JSON
  NOW()

```

## イベント処理

### E001: 画面初期化

**処理順序**:

1. **権限確認**
   - ユーザーがログイン済みであることを確認

2. **顧客一覧データ取得**
   - `GET /api/customers/list` 呼び出し
   - 削除済み顧客を除外した一覧取得

3. **口座番号生成**
   - 新しい口座番号を生成
   - 画面に表示

4. **フォーム初期化**
   - 口座種別を「普通預金」に設定
   - 初期入金額を1000円に設定

### E002: 顧客選択

**処理順序**:

1. **顧客検索・フィルタリング**
   - 入力文字による顧客絞り込み
   - 顧客名・カナでの部分一致検索

2. **顧客情報表示**
   - 選択された顧客の基本情報表示
   - 顧客区分（個人・法人）の確認

3. **口座種別制約チェック**
   - 個人顧客の場合：当座預金選択不可
   - 法人顧客の場合：全種別選択可能

### E003: 口座種別変更

**処理順序**:

1. **種別変更処理**
   - 選択された口座種別を設定

2. **制約チェック**
   - 顧客区分との整合性確認
   - 個人顧客が当座預金を選択した場合は警告

3. **初期入金額制約更新**
   - 定期預金選択時：最低10万円の制約追加
   - その他：制約なし

### E004: 初期入金額入力

**処理順序**:

1. **入力値検証**（デバウンス500ms）
   - 数値形式チェック
   - 金額範囲チェック（1円以上1,000万円以下）
   - 口座種別別の最低金額チェック

2. **エラー表示**
   - 該当項目にエラーメッセージ表示
   - 項目枠を赤色に変更

### E005: 作成ボタン押下

**処理順序**:

1. **最終バリデーション**
   - 全項目の必須チェック
   - 形式・制約チェック
   - 業務ルールチェック

2. **作成確認ダイアログ表示**
   - 作成内容の確認表示
   - 「以下の内容で口座を作成しますか？」

3. **口座ID・口座番号生成**
   - 一意の口座IDを生成
   - 口座番号の最終確認・生成

4. **口座作成API呼び出し**
   - `POST /api/accounts` 呼び出し
   - 口座データを送信

5. **作成結果処理**
   - **成功時**: 成功メッセージ表示、詳細画面に遷移
   - **失敗時**: エラーメッセージ表示、フォーム状態維持

6. **監査ログ記録**
   - `audit_logs`に作成履歴記録

### E006: キャンセルボタン押下

**処理順序**:

1. **入力確認**
   - フォームに入力値があるかチェック

2. **キャンセル確認ダイアログ表示**（入力値がある場合）
   - 「入力内容が破棄されます。よろしいですか？」

3. **画面遷移**
   - 口座一覧画面に遷移（`/accounts/list`）

## データベース操作詳細

### 口座ID生成ロジック

```sql
-- 口座ID生成（例：ACC20240101001）
SELECT
  'ACC' || TO_CHAR(NOW(), 'YYYYMMDD') ||
  LPAD((
    SELECT COALESCE(MAX(
      CAST(SUBSTRING(account_id FROM 12) AS INTEGER)
    ), 0) + 1
    FROM accounts
    WHERE account_id LIKE 'ACC' || TO_CHAR(NOW(), 'YYYYMMDD') || '%'
  )::TEXT, 3, '0') as new_account_id;
```

### 重複チェック

```sql
-- 口座番号重複チェック
SELECT COUNT(*)
FROM accounts
WHERE account_number = $1;

-- 顧客の同一種別口座チェック
SELECT COUNT(*)
FROM accounts
WHERE customer_id = $1
  AND account_type = $2
  AND status != 'CLOSED';
```

## エラーハンドリング

| エラー種別         | 条件                       | メッセージ                                     | 対応テーブル |
| ------------------ | -------------------------- | ---------------------------------------------- | ------------ |
| 顧客不存在         | 選択された顧客が削除済み   | 「選択された顧客は存在しません」               | `customers`  |
| 口座種別制約       | 個人顧客の当座預金選択     | 「個人顧客は当座預金を開設できません」         | -            |
| 重複口座           | 同一顧客・同一種別口座存在 | 「この顧客は既に同じ種別の口座を持っています」 | `accounts`   |
| 初期入金額不足     | 1円未満の入金額            | 「初期入金額は1円以上必要です」                | -            |
| 定期預金入金額不足 | 定期預金で10万円未満       | 「定期預金の初期入金額は10万円以上必要です」   | -            |
| 口座番号生成失敗   | 口座番号生成エラー         | 「口座番号の生成に失敗しました」               | `accounts`   |
| データ作成失敗     | データベース作成エラー     | 「口座の作成に失敗しました」                   | `accounts`   |
| ネットワークエラー | API通信失敗                | 「通信エラーが発生しました」                   | -            |

## 表示フォーマット

### 口座種別選択肢

| DB値          | 表示名   | 説明                     | 制約           |
| ------------- | -------- | ------------------------ | -------------- |
| SAVINGS       | 普通預金 | 一般的な預金口座         | 制約なし       |
| CHECKING      | 当座預金 | 法人向け決済口座         | 法人顧客のみ   |
| FIXED_DEPOSIT | 定期預金 | 固定期間・金利の預金口座 | 最低10万円必要 |

### 顧客表示フォーマット

- **オートコンプリート形式**: `顧客名（カナ）- 顧客区分`
- **例**: `田中太郎（タナカタロウ）- 個人`

### 金額表示フォーマット

- **入力**: 数値のみ
- **表示**: `¥1,234,567`

### 口座番号表示フォーマット

- **形式**: `1234567890`（10桁）
- **表示**: 等幅フォント、大きめサイズ

## API仕様

### GET /api/customers/list

**レスポンス**: 顧客一覧画面と同じ

### POST /api/accounts

**リクエスト**:

```json
{
  "customerId": "CUST001",
  "accountType": "SAVINGS",
  "initialDeposit": 100000
}
```

**レスポンス（成功）**:

```json
{
  "success": true,
  "message": "口座が正常に作成されました",
  "data": {
    "accountId": "ACC20240101001",
    "customerId": "CUST001",
    "accountNumber": "1234567890",
    "accountType": "SAVINGS",
    "status": "ACTIVE",
    "balance": 100000,
    "createdAt": "2024-01-01T09:00:00Z"
  }
}
```

**レスポンス（失敗）**:

```json
{
  "success": false,
  "message": "この顧客は既に同じ種別の口座を持っています",
  "details": {
    "existingAccountNumber": "0987654321",
    "existingAccountType": "SAVINGS"
  }
}
```

## 口座作成ルール

### 口座種別別制約

| 口座種別      | 顧客区分制約 | 最低入金額 | 重複制約  |
| ------------- | ------------ | ---------- | --------- |
| SAVINGS       | なし         | 1円        | 制限なし  |
| CHECKING      | 法人のみ     | 1円        | 1口座まで |
| FIXED_DEPOSIT | なし         | 10万円     | 制限なし  |

### 自動設定項目

- **口座ID**: `ACC` + `YYYYMMDD` + `連番3桁`
- **口座番号**: 10桁の連番
- **ステータス**: `ACTIVE`（有効）
- **残高**: 初期入金額
