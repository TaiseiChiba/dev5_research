## データベース操作

### 使用テーブル

- **参照テーブル**: `accounts`, `customers`
- **操作種別**: SELECT（口座・顧客一覧取得）

### 口座一覧取得SQL

```sql
SELECT
  a.account_id,
  a.customer_id,
  a.account_number,
  a.account_type,
  a.status,
  a.balance,
  a.created_at,
  a.updated_at,
  c.name as customer_name
FROM accounts a
INNER JOIN customers c ON a.customer_id = c.customer_id
WHERE a.status = 'ACTIVE'
  AND c.is_deleted = false
ORDER BY c.name, a.account_number;
```

## イベント処理

### E001: 画面初期化

**処理順序**:

1. **セッション確認**
   - ログイン状態確認
   - ユーザー権限確認

2. **口座・顧客データ取得**
   - `GET /api/accounts/list` 呼び出し
   - `GET /api/customers/list` 呼び出し
   - 口座と顧客情報を結合

3. **フォーム初期化**
   - 取引タイプを「振込」に設定
   - 取引日を当日に設定
   - その他項目を空に設定

4. **画面表示**
   - 取引入力フォーム表示
   - 口座選択肢を設定

### E002: 取引タイプ変更

**処理順序**:

1. **タイプ変更処理**
   - 選択された取引タイプを設定
   - 関連項目をクリア（口座選択）

2. **表示制御更新**
   - 取引タイプに応じた項目表示・非表示
   - 必須項目の更新
   - ラベル名の更新

3. **バリデーション状態クリア**
   - エラーメッセージクリア
   - 入力状態リセット

### E003: 口座選択

**処理順序**:

1. **口座検索・フィルタリング**
   - 入力文字による口座絞り込み
   - 顧客名・口座番号での部分一致検索

2. **重複選択チェック**
   - 振込元と振込先の重複防止
   - 同一口座選択時の警告表示

3. **残高表示**
   - 選択口座の残高情報表示
   - 残高不足の警告（出金・振込元の場合）

### E004: リアルタイムバリデーション

**処理順序**:

1. **入力値検証**（デバウンス500ms）
   - 金額: 1円以上1,000万円以下
   - 取引内容: 100文字以内
   - 取引日: 営業日チェック

2. **エラー表示**
   - 該当項目にエラーメッセージ表示
   - 項目枠を赤色に変更

3. **文字数カウンター**
   - 取引内容の文字数リアルタイム表示
   - 80文字超過時の警告色表示

### E005: 確認画面へボタン押下

**処理順序**:

1. **最終バリデーション**
   - 全項目の必須チェック
   - 形式・制約チェック
   - 口座選択の整合性チェック

2. **バリデーション結果処理**
   - エラーがある場合は該当項目をハイライト
   - 最初のエラー項目にフォーカス
   - 送信を中止

3. **データ準備**
   - フォーム入力値を取引データ形式に変換
   - 日付文字列をDateオブジェクトに変換

4. **画面遷移**
   - 取引確認画面に遷移（`/transactions/confirmation`）
   - 取引データをstateで引き継ぎ

### E006: キャンセルボタン押下

**処理順序**:

1. **入力確認**
   - フォームに入力値があるかチェック

2. **確認ダイアログ表示**（入力値がある場合）
   - 「入力内容が破棄されます。よろしいですか？」

3. **画面遷移**
   - 取引履歴画面に遷移（`/transactions/history`）

## フォーム制御

### 入力制御

- **送信中**: 全フォーム項目を無効化
- **エラー項目**: 赤枠表示、エラーメッセージ表示
- **必須項目**: ラベルに「\*」表示
- **文字数制限**: リアルタイム文字数表示

### ボタン制御

- **確認画面へボタン**: バリデーションエラー時・口座未取得時は無効化
- **キャンセルボタン**: 送信中は無効化

### オートコンプリート制御

- **検索機能**: 顧客名・口座番号での部分一致
- **表示形式**: `顧客名：口座番号 (残高: ¥1,234,567)`
- **フィルタリング**: 選択済み口座を除外

## 営業日判定

### 営業日ルール

- **営業日**: 平日（月曜日〜金曜日）
- **非営業日**: 土曜日、日曜日、祝日
- **祝日判定**: 日本の国民の祝日

### 判定ロジック

```javascript
// 営業日判定の例
function isBusinessDay(date) {
  const dayOfWeek = date.getDay();
  // 土曜日(6)、日曜日(0)は非営業日
  if (dayOfWeek === 0 || dayOfWeek === 6) {
    return false;
  }
  // 祝日判定（実装は省略）
  return !isHoliday(date);
}
```
