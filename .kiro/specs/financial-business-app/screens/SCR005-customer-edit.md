# SCR005: 顧客編集画面

## 基本情報

- **画面ID**: SCR005
- **画面名**: 顧客編集画面
- **URL**: `/customers/:customerId/edit`
- **実装ファイル**: `src/components/customer/CustomerEdit.tsx`
- **アクセス権限**: 認証済みユーザー

## データベース操作

### 使用テーブル

- **メインテーブル**: `customers`
- **操作種別**: SELECT（詳細取得）、UPDATE（更新）

### 顧客詳細取得SQL

```sql
SELECT
  customer_id,
  name,
  phonetic_name,
  customer_type,
  contact_info,
  is_deleted,
  created_at,
  updated_at
FROM customers
WHERE customer_id = $1
  AND is_deleted = false;
```

### 顧客情報更新SQL

```sql
UPDATE customers
SET
  name = $2,
  phonetic_name = $3,
  customer_type = $4,
  contact_info = $5,
  updated_at = NOW()
WHERE customer_id = $1
  AND is_deleted = false;
```

## イベント処理

### E001: 画面初期化

**処理順序**:

1. **URLパラメータ取得**
   - `customerId`をURLから取得
   - パラメータ検証

2. **顧客詳細データ取得**
   - `GET /api/customers/:customerId` 呼び出し
   - `customers`テーブルから詳細情報取得

3. **フォーム初期化**
   - 取得データでフォーム項目を初期化
   - `contact_info`JSONから各項目を展開

4. **画面表示**
   - 編集フォーム表示
   - 顧客番号を読み取り専用で表示

### E002: フォーム入力値変更

**処理順序**:

1. **入力値取得**
   - 変更された項目の値を取得

2. **リアルタイムバリデーション**
   - 入力値の形式チェック
   - エラーがある場合は該当項目にエラー表示

3. **状態更新**
   - フォーム状態を更新
   - エラー状態をクリア（修正時）

### E003: 保存ボタン押下

**処理順序**:

1. **フォームバリデーション**
   - 必須項目チェック
   - 形式チェック（メール、電話番号、郵便番号、カナ）
   - 文字数制限チェック

2. **バリデーション結果処理**
   - エラーがある場合は該当項目をハイライト
   - エラーメッセージ表示
   - 送信を中止

3. **更新データ準備**
   - フォーム入力値を取得
   - `contact_info`をJSON形式に変換
   - 空文字列をundefinedに変換

4. **更新API呼び出し**
   - `PUT /api/customers/:customerId` 呼び出し
   - 更新データを送信

5. **更新結果処理**
   - **成功時**:
     - 成功メッセージ表示
     - 2秒後に顧客詳細画面に自動遷移
   - **失敗時**:
     - エラーメッセージ表示
     - フォーム状態維持

### E004: キャンセルボタン押下

**処理順序**:

1. **変更確認**
   - フォームに未保存の変更があるかチェック

2. **確認ダイアログ表示**（変更がある場合）
   - 「変更が保存されていません。破棄しますか？」

3. **画面遷移**
   - 顧客詳細画面に遷移（`/customers/:customerId`）

### E005: 戻るボタン押下

**処理順序**:

1. **画面遷移**
   - 顧客詳細画面に遷移（`/customers/:customerId`）

| エラー種別           | 条件                                  | メッセージ                                             | 対応テーブル |

## フォーム制御

### 入力制御

- **保存中**: 全フォーム項目を無効化
- **エラー項目**: 赤枠表示、エラーメッセージ表示
- **必須項目**: ラベルに「\*」表示

### ボタン制御

- **保存ボタン**: バリデーションエラー時は無効化
- **キャンセルボタン**: 保存中は無効化
- **戻るボタン**: 常に有効

### 自動保存機能

- **実装なし**: 明示的な保存操作のみ
- **一時保存**: LocalStorageに下書き保存（オプション）
