# SCR001: ログイン画面

## 基本情報

- **画面ID**: SCR001
- **画面名**: ログイン画面
- **URL**: `/login`
- **実装ファイル**: `src/components/auth/LoginScreen.tsx`
- **アクセス権限**: 全ユーザー（未認証）

## データベース操作

### 使用テーブル

- **メインテーブル**: `users`
- **操作種別**: SELECT（認証）

### 認証処理SQL

```sql
SELECT
  user_id,
  password_hash,
  user_role,
  is_active,
  created_at,
  updated_at
FROM users
WHERE user_id = $1
  AND is_active = true;
```

## イベント処理

### E001: ログインボタン押下

**トリガー**: ログインボタンクリック、またはEnterキー押下

**処理順序**:

1. **入力値検証**
   - 利用者IDが空でないことを確認
   - パスワードが空でないことを確認
   - 検証失敗時はエラーメッセージ表示して終了

2. **認証API呼び出し**
   - エンドポイント: `POST /api/auth/login`
   - リクエストボディ:
     ```json
     {
       "userId": "入力された利用者ID",
       "password": "入力されたパスワード"
     }
     ```
   - ローディング状態表示

3. **データベース認証処理**
   - `users`テーブルから利用者情報取得
   - bcryptでパスワードハッシュ比較
   - `is_active = true`の確認

4. **認証結果処理**
   - **成功時**:
     - セッション情報をLocalStorageに保存
     - ダッシュボード（`/`）にリダイレクト
   - **失敗時**:
     - エラーメッセージ表示
     - フォーム状態維持

### データベース更新処理

認証成功時に監査ログを記録：

```sql
INSERT INTO audit_logs (
  log_id,
  user_id,
  action,
  entity_type,
  entity_id,
  new_values,
  timestamp
) VALUES (
  $1, -- UUID
  $2, -- user_id
  'LOGIN',
  'USER',
  $3, -- user_id
  $4, -- ログイン情報JSON
  NOW()
);
```

## エラーハンドリング

| エラー種別         | 条件                              | メッセージ                                                         | 対応テーブル |
| ------------------ | --------------------------------- | ------------------------------------------------------------------ | ------------ |
| 必須項目未入力     | 利用者IDまたはパスワードが空      | 「利用者IDとパスワードを入力してください」                         | -            |
| 認証失敗           | `users`テーブルに該当レコードなし | 「利用者IDまたはパスワードが正しくありません」                     | `users`      |

| ネットワークエラー | API通信失敗                       | 「接続エラーが発生しました。しばらく待ってから再試行してください」 | -            |

## セキュリティ考慮事項

### パスワード処理

- フロントエンドでは平文パスワードを送信
- バックエンドでbcryptによるハッシュ比較
- パスワードハッシュはフロントエンドに送信しない

### セッション管理

- 認証成功時にセッション情報をLocalStorageに保存
- セッション情報には以下を含む：
  ```json
  {
    "userId": "USER001",
    "userRole": "GENERAL_STAFF",
    "sessionId": "uuid",
    "expiresAt": "2024-01-01T12:00:00Z"
  }
  ```

### 監査ログ

- すべてのログイン試行を`audit_logs`テーブルに記録
- 成功・失敗の両方を記録
- IPアドレス、タイムスタンプを含む

## バリデーションルール

| 項目       | ルール            | エラーメッセージ                 | 検証タイミング |
| ---------- | ----------------- | -------------------------------- | -------------- |
| 利用者ID   | 必須、50文字以内  | 「利用者IDを入力してください」   | 送信時         |
| パスワード | 必須、255文字以内 | 「パスワードを入力してください」 | 送信時         |

## API仕様

### POST /api/auth/login

**リクエスト**:

```json
{
  "userId": "string (max 50)",
  "password": "string (max 255)"
}
```

**レスポンス（成功）**:

```json
{
  "success": true,
  "user": {
    "userId": "USER001",
    "userRole": "GENERAL_STAFF"
  },
  "message": "ログインが成功しました"
}
```

**レスポンス（失敗）**:

```json
{
  "success": false,
  "message": "利用者IDまたはパスワードが正しくありません"
}
```
